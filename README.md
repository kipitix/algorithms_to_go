# Algorithms to Go

Компактный практический конспект по алгоритмам для олимпиадного программирования
(школьные и студенческие олимпиады, Codeforces, ACM ICPC, LeetCode easy-medium)
с примерами кода на Go.

## Содержание

Полный текст книги: [docs/algorithms_book.md](docs/algorithms_book.md)

Основные темы:

- Как определить тип задачи и оценить ограничения по времени и памяти
- Сортировка и бинарный поиск
- Два указателя и скользящее окно
- Префиксные суммы и разностные массивы
- Структуры данных: стек, очередь, куча, DSU
- Деревья отрезков и дерево Фенвика
- Жадные алгоритмы
- Динамическое программирование
- Графы: обходы, кратчайшие пути, остовные деревья, топология, компоненты
- Строки: хэши, префикс- и Z-функции
- Комбинаторика и теория чисел

Каждая глава содержит идею алгоритма, оценку сложности, типичные ошибки и рабочий
пример кода на Go с использованием только стандартной библиотеки.
